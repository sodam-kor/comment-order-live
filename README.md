# 제안 2. 댓글 주문형 라이브

4-(1) 2차시에 써요. 교과서의 '댓글 주문형' 만화를 반에서 재현해요. 수용자(학생)가 요청 댓글과 공감을 남기면, 생산자(교사나 그림 모둠)가 골라서 다음 회차에 반영해요.

- 화면: 이 폴더의 `index.html` 한 파일 (GitHub Pages에 올림)
- 저장: **`1_앱스스크립트`** (댓글·공감·그림이 구글 시트에 저장돼요)

## 설치하기

1. **`1_앱스스크립트`를 먼저 설치**하고 웹 앱 URL을 복사해 둡니다. (그 폴더 README 1~9단계)
2. 이 폴더의 `index.html`을 메모장이나 VS Code로 열고, 아래쪽의 이 줄을 찾습니다.
   ```js
   var API_URL = 'https://script.google.com/macros/s/여기에_배포_ID/exec';
   ```
   따옴표 안을 복사해 둔 웹 앱 URL로 바꾸고 저장합니다.
   > 이 주소는 공개돼도 괜찮아요. 교사 기능은 비밀번호(`TEACHER_PASSWORD`)로 막혀 있어요. **Gemini·나이스 키는 이 파일에 절대 넣지 마세요.**
3. GitHub에서 **New repository**를 누르고 이름을 `comment-order-live`로 정합니다. **Public**으로 만듭니다.
4. **Add file → Upload files**로 `index.html`을 올리고 **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**에서 Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
6. 1~2분 뒤 `https://<내 GitHub 아이디>.github.io/comment-order-live/` 주소가 열려요.

## 수업에서 쓰기 (2차시)

1. 교사 기기에서 주소를 열고 **선생님(생산자)으로 들어가기**를 누릅니다. 비밀번호는 1_앱스스크립트의 `TEACHER_PASSWORD`와 같아요.
2. **반**을 고릅니다. (📅 오늘 시간표로 찾기도 가능)
3. **새 회차 올리기**에 첫 장면의 설명을 쓰고, 그림판에 그리거나 사진을 올린 뒤 **🚀 새 회차 올리기**를 누릅니다.
   - 소재가 필요하면 **🍱 오늘 급식**이나 **🗓 학교 행사**를 눌러 나이스에서 불러올 수 있어요.
4. 학생들은 학생으로 로그인(학년·반·번호·이름)한 뒤 **요청 댓글**을 달고 친구 댓글에 **♡ 공감**을 눌러요. 한 회차에 1인당 5개까지 달 수 있어요.
5. 교사 화면에서 공감순으로 정렬된 댓글을 보고, 반영할 댓글에 **✨**를 누릅니다. 학생 화면에 **✨ 반영됨**이 떠요.
6. **🔒 댓글 닫기** → 반영한 다음 장면을 **새 회차로 올리기** → 반복합니다.
7. 마지막에 **🪞 성찰 쓰기**를 누르면 학생이 "내 댓글이 작품을 어떻게 바꿨는지" 씁니다.
8. **📊 참여 분석** 탭에서 회차별 댓글·참여 학생·공감·반영 수를 보며 **수용자 참여 양상**을 함께 분석해요. 아직 댓글을 달지 않은 번호도 나와요.

> 생산자를 학생 모둠에게 맡기려면 교사 기기(또는 교사가 로그인한 태블릿)를 그 모둠에게 건네주세요.

## 정리

단원이 끝나면 **📊 참여 분석 → 기록 지우기**로 그 반의 기록을 모두 지울 수 있어요.

## 알아 둘 점

- 화면을 고쳐 GitHub에 다시 올리면 바로 반영돼요. 앱스스크립트 쪽을 고쳤다면 그쪽은 **새 버전으로 배포**해야 해요.
- 그림은 자동으로 작게 줄여 저장돼요. 아주 큰 사진은 올라가지 않을 수 있어요.
